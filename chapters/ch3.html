多智能体：模式、失败与框架

本章定位（循序渐进）：从单 agent 到多 agent 是 2025 年最大的架构跃迁，但失败率极高——先学失败分类再学框架，避免'为了多智能体而多智能体'。

本章论文（总分总速览，点击进入深度笔记）

How We Built Our Multi-Agent Research System

Anthropic · 工程实战复盘
问题研究型任务串行执行慢、覆盖窄；单 agent 上下文装不下多源信息。
理念orchestrator-worker：LeadAgent 拆解并行分派 subagent；状态增量保存；用 token 买广度。
总结多智能体的工业级样板，附完整成本账（90.2% 提升 / 15× token / 80% 方差）。
AI 应用平台 R2/R3 团队管理

Why Do Multi-Agent LLM Systems Fail?（MAST 失败分类法）

UC Berkeley 等（Cemri, Pan 等） · 论文（NeurIPS 2025）
问题多智能体系统经常不如单 agent，失败原因从未被体系化归因。
理念对 LangGraph/AutoGen/CrewAI 真实 trace 实证标注：14 种失败模式、三大层级（规格/智能体间对齐/任务验证），失败大头在 agent 间对齐与验证缺失。
总结给'要不要上多智能体'提供风险清单与排障检查单。
AI 应用平台 团队管理

AgentScope 1.0: A Developer-Oriented Technical Report

阿里巴巴（Qwen 团队生态） · 技术报告 + 开源框架
问题主流 agent 框架黑盒程度高：失败难定位、状态难重放、并发难控。
理念agent as actor + 显式异步消息：并发天然、失败可定位、可重放；配套 Studio 可视化。
总结框架层面系统性回应 MAST 的失败模式。
AI 应用平台 轮询框架

  • 掌握 orchestrator-worker 拓扑与 15× token 成本账
  • 记住 MAST 三层级 14 种失败模式
  • 能给出自研编排 vs 开源框架的选型论证
与简历项目的关联：你 0→1 时选择意图路由的确定性链路而非多智能体——用 MAST 的失败数据反推这个决策的先见性。
