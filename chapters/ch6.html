本章论文（总分总速览，点击进入深度笔记）

UI-TARS: Pioneering Automated GUI Interaction with Native Agents

字节跳动 Seed 团队 · 论文 + 开源模型
问题企业大量存量系统没有 API，agent 只能调结构化接口，覆盖受限。
理念纯视觉原生 GUI agent：统一动作空间（键鼠/系统调用），感知-行动迭代，含错误恢复训练数据。
总结交互形态从 API 扩展到'像人一样操作界面'。
与 R1 无直接关联，作为'多模态 agent 交互趋势'的谈资

BrowseComp: A Simple Yet Challenging Benchmark for Browsing Agents

OpenAI · 论文 + 基准
问题browsing/deep research 缺乏'难且可客观验证'的评测基准。
理念难找易验：1266 道需多跳检索与交叉验证的问题，答案简短易核对，完美适配 RL 与评估。
总结评测设计的方法论样板——可直接迁移到自建评估集。

MCP 与 A2A：Agent 互操作协议双雄

Anthropic（MCP）/ Google 发起、Linux 基金会（A2A） · 协议标准
问题工具接入 N×M 胶水代码、agent 之间无法互操作，生态碎片化。
理念MCP（agent↔工具，JSON-RPC，Tools/Resources/Prompts）+ A2A（agent↔agent，Agent Card 与任务生命周期，不透明协作）。
总结互操作标准层：MCP 管'手和眼'，A2A 管'外交'。
AI 应用平台 Apache Fury 团队管理

Berkeley Function Calling Leaderboard V3（BFCL V3）

UC Berkeley（Gorilla 团队） · 基准 + 论文
问题工具调用评测停留在单轮参数匹配，无法反映多轮、状态与'该不该调'的判断。
理念V3 升级：multi-turn & multi-step、状态性评估、irrelevance detection（识别不相关请求）。
总结工具调用质量的标准规尺——irrelevance detection 与意图识别/拒答同构。
