DeepSeek-R1: Incentivizing Reasoning Capability in LLMs via Reinforcement Learning

DeepSeek · 论文 + 开源模型
问题推理能力被闭源模型垄断：开源模型'不会思考'，规划要靠工程流程硬补。
理念纯 RL（GRPO）激发推理涌现（反思/自验证/aha moment）；蒸馏把推理能力迁移给小模型。
总结开源 agent 时代的起点：规划能力开始内生化，工程分工随之改变。

Qwen3 Technical Report

阿里巴巴 Qwen 团队 · 论文 + 开源模型
问题企业私有化 agent 部署需要端云协同、成本可控、可商用的模型家族。
理念hybrid thinking/non-thinking 模式可切换 + 0.6B~235B-A22B 全家族开源（Apache 2.0），原生强化工具调用。
总结私有化 agent 部署的事实标准底座。

Kimi K2: Open Agentic Intelligence

月之暗面 Moonshot AI · 论文 + 开源模型
问题真实工具调用数据稀缺，开源模型'不敢调、不会调'工具。
理念大规模 agentic 数据合成（数千工具轨迹）+ 联合 RL（self-critique rubric 奖励 + 通用可验证奖励）。
总结把'会用工具'变成可训练目标，定义 agentic model 类别。

GLM-4.5: Agentic, Reasoning, Coding (ARC)

智谱 AI / 清华系 · 论文 + 开源模型
问题agent 同时需要思考、工具、代码三种能力，多数模型只偏其一。
理念ARC 统一训练（Agentic/Reasoning/Coding）+ slime RL 基建 + MIT 全开源。
总结国产 agentic 原生均衡旗舰，私有化生态热门。

LongCat-Flash Technical Report

美团 LongCat（龙猫）团队 · 论文 + 开源模型
问题大参数 MoE 推理成本高，而 agent 工作负载波动大、预算敏感。
理念ScMoE 混合连接 + 零计算专家：按 token 难度自适应分配算力（560B 总参、27~31B 激活）。
总结把'动态负载调度'思想做进模型架构——与你自研的动态负载自适应调度同构。
